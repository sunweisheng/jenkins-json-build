# v3.2.1 版本说明

发布日期：2026-08-24

## 修复

- Windows 静态 Agent 的工具检查现在能识别配置中的绝对可执行文件路径，MSBuild 和 VSTest 可直接使用 Windows 节点配置的安装位置。
- 旧版 .NET Framework/MSBuild V3 示例增加 `MSBUILD_WORK_DIR`，构建和单元测试在项目目录执行；VSTest 路径改由 JSON 配置传入，不再依赖旧机器的硬编码目录。
- 旧版 .NET Framework/MSBuild V2 示例同样改为从 JSON 配置读取 MSBuild 与 VSTest 路径，并实际执行单元测试。
- .NET 示例的 NuGet 引用路径已修正，覆盖率工具仍作为可选配置，不影响普通单元测试。

## 验证状态

- 本地 OpenJDK 21 下共享类库 Maven 测试和 V2 转换器测试通过。
- Windows 静态 Agent 的 V2 验收构建 `#12` 通过 VSTest 的 3 项测试；V3 验收构建 `#15` 成功执行 `My.msbuild /t:RunUnitTestsInMs` 并归档构建制品。
- iOS 静态 Mac Agent 验收构建通过 5 项模拟器测试；Maven 和 Python 验收构建在 Kubernetes Pod 中通过。

## 已知限制

- Apple 真实签名、Archive 和 IPA 导出仍需要真实 P12 与 provisioning profile 才能验收；本版本未使用示例凭据替代。
