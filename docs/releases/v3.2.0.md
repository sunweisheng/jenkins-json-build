# v3.2.0 版本说明

发布日期：2026-08-12

## 新增

- 新增 Node/npm、Android/Gradle、React Native Android、iOS/Xcode、React Native iOS 和旧版 .NET Framework/MSBuild 模板。
- 新增 `agentServer`、`customCheckbox` 参数及旧 `multiChoice + customCheckbox` 兼容。
- Agent Server Parameter 固定为 `1.23.v3f9770f9cc1a_`，构建参数页由服务端渲染全部 Jenkins 节点，并将历史选择置顶。
- 新增参数首次初始化 `NOT_BUILT`、历史选择保留、项目全不选阻断和静态 Agent 源码检出前检查。
- 新增 `npm`、`gradle`、`msbuild`、`coverage`、`xcodebuild`、`xcodeCoverage`、`appleSigning`。
- SonarQube 增加非 Maven 脚本方式。
- V2 转换增加 npm、Gradle、MSBuild、单一 Xcode 动作、Jest/LCOV、OpenCover 和 xcresult 覆盖率。
- 新增固定摘要、非 root、无 Docker Socket、无 hostPath、无特权的多语言 Kubernetes Pod 模板。
- Node 依赖安装阶段默认在临时网络失败后重试两次；React Native Android 明确使用 Jest LCOV，避免模板继承后误用 Android JaCoCo 路径。
- Jenkins Kubernetes Cloud 默认 `containerCap` 调整为 `2`，允许同时运行两个 Agent Pod；该参数不控制节点位置，4 GB 节点必须另用标签、亲和性、污点或等效调度策略保证每台只运行一个构建 Pod。
- Jenkins Controller 启动探针调整为 15 分钟，避免 NFS Jenkins Home 在插件扫描和任务加载期间被 Kubernetes 按 Chart 默认的 2 分钟误重启。
- Helm values 使用 Chart 原生字段配置 `disableRememberMe` 和 API Token 策略，避免与自定义 JCasC 重复声明；复用管理员 Secret 时启用 Chart 的现有 Secret 投影，不创建或覆盖 Secret。
- React Native Android 模板显式使用进程内 Kotlin 编译，4 GB Node1 验收配置使用 768 MiB Gradle 堆、384 MiB Metaspace 和单工作线程；通用 Pod 的资源默认值保持不变。
- Linux ARM64 验收项目使用 React Native `0.81.6` 旧架构，避免依赖官方尚未提供的 Linux ARM64 NDK；需要 React Native `0.82+`、新架构或原生模块时必须覆盖兼容 NDK 镜像或使用 amd64 Agent。

## 兼容性

- V2.1 行为保持兼容。
- Java、Maven、BuildKit、Kaniko 和 Helm 原有 V3 行为保持兼容。
- iOS 只支持 Mac Agent；旧版 .NET Framework 只支持 Windows Agent；不增加现代 `dotnet`。
